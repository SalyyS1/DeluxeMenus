## Compatibility

- Java 11 or newer
- Paper, Spigot, or Folia-compatible server software
- PlaceholderAPI is required
- Current compile target: Paper 1.21.11

The release JAR keeps runtime compatibility checks for features that only exist
on newer Minecraft versions. For example, Minecraft dialogs require 1.21.6 or
newer.
